# Little Lingos Classroom

The Little Lingos learning platform (LMS) for children aged 3.5 to 15, their parents, trainers and the academy team.

- **Live app:** https://classroom.littlelingos.in
- **Project reference:** [source/PROJECT.md](source/PROJECT.md) covers how it's built, every feature, the safety rules, deploying and costs.
- **Setup guide:** [source/SETUP.md](source/SETUP.md) covers creating the database and putting the site online.

The files in this top folder are the published website. `source/` holds everything used to build it: the build scripts and feature files (`source/build`), the database rules (`source/supabase`) and the local tests (`source/test`).
